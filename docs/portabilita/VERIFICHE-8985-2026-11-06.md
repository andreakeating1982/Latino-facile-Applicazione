## Uso e limiti

L'archivio non include `.env`, chiavi, dati degli studenti, database, `.git`, dipendenze installate o build. La scansione di firme note non è un audit di sicurezza completo. È un pacchetto sorgente: non pubblica nulla su GitHub o Render automaticamente. In GitHub caricare nella radice della repository il contenuto della cartella estratta, inclusi i file nascosti pubblici.

La prova mobile è emulata, non su un telefono fisico; i PDF incorporano OpenDyslexic ma non sono taggati, senza certificazione PDF/UA o WCAG. I controlli non certificano accuratezza grammaticale generale, OCR su foto reali o efficacia per tutti gli studenti BES/DSA. Una nuova installazione richiede una propria chiave valida per le funzioni IA; la clonazione non adatta automaticamente il motore del latino a un'altra lingua.

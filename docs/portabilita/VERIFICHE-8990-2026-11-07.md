## Ricostruire e verificare il pacchetto

Il **rapporto esterno** `.zip.verifica.json` registra CRC, file e SHA-256 rispetto al commit di export, confronto dei sorgenti applicativi col codice pubblicato e scansione prudenziale di firme note. Il `.zip.sha256` è esterno per non alterare l'archivio che verifica.

Per sapere se una **specifica consegna finale** è stata ricostruita, consultare il rapporto di ricostruzione allegato a quella consegna: gli esiti della [verifica 8985](VERIFICHE-8985-2026-11-06.md) riguardano il vecchio candidato e non dimostrano automaticamente l'esito dello ZIP nuovo. I passaggi per ripeterla senza credenziali, migrazioni o dati reali sono in [ESPORTAZIONE](../ESPORTAZIONE.md).

Il pacchetto non include `.env`, chiavi, dati studenti, database, `.git`, dipendenze o build; non carica automaticamente file su GitHub e non crea servizi Render. La scansione di firme note non è un audit completo della sicurezza.

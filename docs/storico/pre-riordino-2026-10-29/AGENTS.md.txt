## 1. Che cos'è questa repository

«Latino Facile» è una web app didattica che **colora le frasi latine parola per
parola**: l'utente scrive (o carica via OCR) una o più frasi, il server le
analizza con il motore **Whitaker's Words** arricchito da un glossario italiano,
ogni parola viene colorata in base alla categoria grammaticale (legenda
universale del quaderno), e si può scaricare il **PDF colorato**, vedere la
**traduzione** (mostra/nascondi) e usare strumenti **inclusivi** (font
OpenDyslexic, barra di accessibilità, lettura ad alta voce).

Stack: **Vite 7 + React 19 + TypeScript + Tailwind CSS 4 + shadcn/ui** (frontend),
**Express 4 + tRPC 11 + Drizzle ORM** (backend). PostgreSQL è **OPZIONALE**: il
cuore dell'app (analisi, colorazione, OCR, PDF, traduzione con glossario)
funziona anche senza database.

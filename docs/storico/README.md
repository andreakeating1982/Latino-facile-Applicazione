# Archivio non operativo

La cartella `pre-riordino-2026-10-29/` conserva **integralmente** le guide, il registro e il manifest precedenti al riordino del pacchetto. L'estensione `.txt` è intenzionale: quelle versioni contenevano note incrementali e indicazioni a volte superate o contraddittorie.

**Non usare i comandi o le affermazioni di questo archivio come istruzioni correnti.** In particolare non ripristinare limiti da 200 parole/400 caratteri, sconosciuti bianchi, vecchi grigi, `modal=false` del cropper, link al quaderno, footer inesistenti, vecchi chunk IA o l'idea che il database serva all'IA.

Fonti correnti: [AGENTS.md](../../AGENTS.md), [REBUILD.md](../../REBUILD.md), [ADATTARE.md](../../ADATTARE.md), [RENDER.md](../../RENDER.md), [manifest.json](../../manifest.json) e soprattutto il codice applicativo.

L'archivio è mantenuto per non perdere decisioni e appunti, non per aumentare la superficie di configurazione. Nessun asset dell'app viene eliminato dal riordino.
